# Agario Game

## Overview
Agario Game is a multiplayer online game inspired by the original Agar.io. Players control a cell in a map representing a microbe and must consume other players to grow larger while avoiding being eaten by bigger cells.

## Features
- Multiplayer mode to play against friends or random players.
- Various skins to customize your cell.
- Simple and intuitive controls.
- Responsive design for various devices.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/atik8989/agario-game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd agario-game
   ```
3. Open `index.html` in your web browser to start playing.
